# Research prompts - how to use

Each prompt file is ONE step: paste it into a new chat, wait for the one text file it asks for, then send the next file.
Every folder lists its files in the order to run them. The answers go in `Bfa-8.3.7 Research/# Ai Research prompts` (or wherever you keep them).
