AUDIT - Twink29_Hunter_1_Items.txt
File under audit: 155 lines, step 1 of 3, written before the mail-only rule
was set. 20 claims checked: 11 pass, 4 corrected, 5 unverified.
Sources opened for this audit: the same filtered item searches the file was
built from (rare quality, required level 26-29, item level 35 or less, per
armour and weapon type), the heirloom mail list, and the two jewellery
rows carried from the druid set.

1. THE BIG ONE - LEATHER SHOULD NOT BE IN A HUNTER FILE
   Hunters wear mail. The first draft listed leather as ordinary gear,
   complete with a note that mixing armour types costs the all-mail bonus,
   and it did that because the item search returns leather pieces with
   better numbers than the mail ones. That is the wrong frame: a hunter
   bot is geared in mail, and a leather row is at best a stopgap.
   Wrong: 15140 Cutthroat's Mantle, 7727 Watchman Pauldrons, 2278 Forest
   Tracker Epaulets, 3020 Enduring Cap, 9455 Emissary Cuffs, 18948
   Barbaric Bracers, 7756 Dog Training Gloves, 888 Naga Battle Gloves,
   6690 Ferine Leggings - all leather, all presented as hunter armour.
   The rebuild carries none of them. Where a mail slot has no rare item in
   the window, the rebuilt file says so instead of substituting leather.

3. THE ARATHI BASIN PAIR - PASS WITH A CAVEAT
   10 PASS  20090 and 20093 (Alliance), 20152 and 20157 (Horde) are the
            hunter's 20-29 battleground belt and boots, item level 33,
            required 28. The search page tags all four "Hunter, Shaman",
            which is what makes them the hunter set.
   11 CAVEAT  All four are filed under the leather category, not the mail
            one, so under a strict mail-only rule they are a downgrade
            piece, not core gear. The rebuilt file keeps them but marks
            them. This is the one place the mail rule and the class tag
            disagree, and the file should not pretend otherwise.

4. THE EMPTY SLOTS - CORRECTED FROM "THIN" TO "EMPTY"
