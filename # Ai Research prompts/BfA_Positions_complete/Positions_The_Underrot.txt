==============================================================================
THE UNDERROT - POSITIONS AND NUMBERS, BFA 8.3.7 BUILD 35662
==============================================================================
 Map id 1841. Four boss encounters: Elder Leaxa 131318, Cragmaw the
 Infested 131817, Sporecaller Zancha 131383, Unbound Abomination
 133007 - plus a Titan Keeper Hezrel event that the instance script
 counts as an encounter slot.
 Companion file to the tactics document. Every number is tagged with
 the source it came from. Anything I could not read is written
 "unverified".

==============================================================================
0. READ THIS FIRST - WHAT THIS FILE CAN AND CANNOT GIVE
==============================================================================

  Tags:
    [SRV]  a line in the 8.3.7 script: the_underrot.h,
           instance_the_underrot.cpp, the_underrot.cpp, or one of the
           four boss files.
    [DB]   a row in a world SQL update - here the Underrot SmartAI
           file, 32 rows over 20 creature entries.
    [MDT]  Method Dungeon Tools BattleForAzeroth/TheUnderrot.lua:
           name, creature id, per-kill force, health, level, points.
    [DBM]  DBM-Party-BfA/TheUnderrot/*.lua: a stopwatch value.
    [LW]   LittleWigs BfA/Underrot/*.lua: a second stopwatch value.
    [CALC] arithmetic on the numbers above, inputs always given.
    unverified   no readable source carries the value. Never a guess.

  THE HEADLINE: still no creature spawn table for map 1841. The
  TrinityCore 9.x and 11.x world updates that mention these creature
  ids carry creature_template_difficulty and scaling rows, not
  creature rows with coordinates, and the vSLDB Underrot SQL is
  smart_scripts only - zero INSERT INTO creature. So
  every boss spawn point, tank point, safe spot and pull position is
  unverified in world coordinates, with two exceptions that are exact:
    - the ten script Position constants in 3.1, which carry x, y and
      z, six of them with an orientation as well;
    - the three-point descent path in 3.2, which is the only place the
      script moves a player in this instance.
  Unlike The MOTHERLODE!! this dungeon does have SmartAI trash (8.3),
  so section 8 is not empty - but SmartAI rows carry timers, not
  spawn points, and they never carry coordinates.

2. THE INSTANCE FRAME
==============================================================================

  2.1 Map 1841, from RegisterInstanceScript(instance_the_underrot,
      1841) at the bottom of instance_the_underrot.cpp [SRV].
  2.2 EncounterCount = 8 [SRV]. That is not eight bosses. The enum
      lists four bosses plus two Faceless Corruptor slots and two
      Hezrel slots, and it starts at 1, not 0:
        DATA_ELDER_LEAXA = 1, then DATA_CRAGMAW_THE_INFESTED,
        DATA_SPORECALLER_ZANCHA, DATA_UNBOUND_ABOMINATION,
        DATA_FACELESS_CORRUPTOR_1, DATA_FACELESS_CORRUPTOR_2,
        DATA_EVENT_HERZEL and DATA_BOSS_HERZEL in that order.
      Only the first value is written in the header; the other seven
      follow by enumeration, which makes them 2 to 8 [CALC].
      So this instance is ONE-based, the opposite of The MOTHERLODE!!.
      A row that opens encounter 0 opens nothing here.
  2.3 BOSS BOUNDARIES, all four exact [SRV]:
        Leaxa      ZRangeBoundary(44.181206, 63.479584)
        Cragmaw    CircleBoundary(Position(862.497009, 982.315979,
                   39.231701), 90.0)
        Zancha     ZRangeBoundary(20.0, 40.0)
        Abomination ZRangeBoundary(-200.0, -150.0)
      These are leash volumes, not spawn points. The Cragmaw circle is
      the only horizontal boundary in the instance, and it is the only
      arena whose centre and radius are both readable.
  2.4 NO DOOR DATA. The instance script has OnCreatureCreate, SetData
      and nothing else: no LoadDoorData, no OnGameObjectCreate, no
      OnPlayerEnter. Two game objects are handled by id only, in
      SetData(DATA_EVENT_HERZEL, DONE): 296384 GOB_PYRAMID_WEB is
      removed from the world and 296385 GOB_PYRAMID_DOOR is opened
      with HandleGameObject. Their positions are unverified.
  2.5 The instance constructor calls
      SummonCreatureGroup(SUMMON_GROUP_BLOODSWORN_DEFILER), group 1.
      Which entry that group contains and where it lands are both DB
      data, so both are unverified; the name and the SmartAI file both
      point at 133912 Bloodsworn Defiler (10.16).
  2.6 TITAN KEEPER HEZREL 134419 IS TWO ENCOUNTER SLOTS BY HEIGHT. In
      OnCreatureCreate the instance checks
      creature->GetPositionZ() < -100.0: below that the creature is
      DATA_BOSS_HERZEL, at or above it DATA_EVENT_HERZEL [SRV].
      So the same entry is the pre-boss event NPC up top and the boss
      helper in the Abomination arena below.

4. BOSS 1 - ELDER LEAXA 131318
==============================================================================

  4.1 SPAWN AND TANK POSITION. Spawn unverified: no creature row with

  4.2 PHASES: NONE. There is no HealthBelowPct and no SetBossState

  4.3 TIMERS, seconds from pull
      ability                     script [SRV]      LW [LW]  DBM [DBM]

      b) BLOOD MIRROR 264603 - the victim, at 16.0 s then every 30.0

         whatever speed the trigger's own movement gives it. The
         trigger lives 30.0 s and carries 260891 as a visual.
      d) SANGUINE FEAST 264757 - heroic and mythic. Every 30.0 s from

         current victim. It also delays the other events by 3.0 s.
      e) SOAK LISTS, KICK ORDER, TANK SWAPS: none. No cast in the file
         sets an interrupt flag and no mechanic counts stacks.

  4.5 THE FLOOR PLAN. Leaxa's arena is the tightest in the instance:

  4.6 SAFE SPOTS, WITH z. Unverified as points. What the script does

      Rot line is 250 yd long, so no fixed spot in a 25 yd arena is
      outside it. Standing at the arena edge only changes when the
      line arrives, not whether it exists.

5. BOSS 2 - CRAGMAW THE INFESTED 131817

  5.1 SPAWN AND TANK POSITION. Spawn unverified. MDT anchor (606.0,
      -300.0) in MDT space, z unverified [MDT]. MDT health 5,379,465,

      TANK: unverified as a coordinate, but the tank's POSITION is

  5.2 PHASES: NONE BY HEALTH. One resource phase: Cragmaw gains energy
      only on heroic and mythic, and Tantrum is the 100-energy event
      (5.4d). No HealthBelowPct anywhere in the file.

  5.3 TIMERS, seconds from pull
      ability                     script [SRV]      LW [LW]  DBM [DBM]
      Indigestion 260793          8.0, then 8.0     19.3     8.3
      Charge 260292               20.0, then 20.0   8.2      8.3
      Tantrum 260333 (H/M)        100 energy       45.0     45
      LittleWigs' second values for these are 10.5 and 43.0 for
      Indigestion and 12.15 and 20.6 for Charge; DBM's repeat is 49.7
      for Indigestion and 20 for Charge. All three sources agree the
      cadence is irregular, and only the script's is the cadence this
      core runs. Tantrum's script path is 100 energy at +2 per 2.0 s,
      i.e. about 100 s of combat if nothing else feeds the bar [CALC];
      both addons bar it at 45 s.

  5.4 ASSIGNED-PLAYER MECHANICS AND EXACT TRIGGERS
      a) CHARGE 260292 - a random target within 100 yd, every 20.0 s.
         On spell finish the script spawns twelve larvae boxes around
         the BOSS: for i in 0..11 it casts 260391 at
         (bossX + urand(2,10), bossY - urand(2,10), bossZ). The x
         offset is always positive and the y offset always negative,
         so the box is one quadrant, not a circle.
      b) INDIGESTION 260793 - the victim, every 8.0 s. On finish it
         spawns four larvae around the VICTIM: (tankX + urand(3,5),
         tankY - urand(3,7), bossZ). Same one-quadrant bias, tighter
         offsets.
      c) TANTRUM 260333 - heroic and mythic only, via the energy bar.
         At 100 energy the boss schedules Tantrum 1.0 s later and
         zeroes the bar. Tantrum sets walk, run and flight speed to
         4.5, goes REACT_PASSIVE, casts 260333 on itself and runs a
         three-point path: (888.63, 967.30, 41.06) then (839.35,
         968.41, 40.61) then (863.21, 1015.53, 39.90). Each waypoint
         is only taken while the Tantrum aura is still on him; at each
         arrival without the aura he clears his motion and returns to
         aggressive at 1.5 speed.
      d) SOAK LISTS, KICK ORDER, TANK SWAPS: none. Nothing in the file
         is interruptible and no cast counts stacks. The one assignment
         shaped mechanic is positional: nobody should stand in the two
         spawn quadrants in (a) and (b).

  5.5 THE FLOOR PLAN. A 90.0 yd circle centred on (862.497009,
      982.315979, 39.231701) is the instance boundary; the boss's own
      check kills every player if the BOSS is 80.0 yd or more from
      (856.38, 981.99, 39.14) (3.3b). Cragmaw's centrePlatform z is
      39.14 and the circle centre z is 39.23, so the arena floor is
      flat to 0.09 yd across the one pair of points the core states
      [CALC]. The Tantrum waypoints sit at z 41.06, 40.61 and 39.90,
      i.e. 1.9, 1.5 and 0.8 yd above that centre.
  5.6 SAFE SPOTS, WITH z. Unverified as named points. The exact ones
      the script does give are the three Tantrum waypoints in 5.4c:
      those are where the boss goes, so for a player they are the three
      places NOT to be during Tantrum. Everything else in the fight is
      generated relative to the boss or the tank, so no fixed safe spot
      exists in code.

6. BOSS 3 - SPORECALLER ZANCHA 131383
==============================================================================

  6.1 SPAWN AND TANK POSITION. Spawn unverified. MDT anchor (539.8,
      -159.2) in MDT space, z unverified [MDT]. MDT health 5,379,465,
      level 122, force 0 [MDT] - the same health figure as Cragmaw,
      which is a coincidence of scaling, not shared data.
      TANK: unverified as a coordinate, but the tank is the role
      Upheaval tries to exclude (6.4a), so the tank's job is to hold
      the boss while two other players soak.
  6.2 PHASES: NONE BY HEALTH. One energy phase: 100 energy schedules
      Festering Harvest 1.0 s later. This is the only boss in the
      instance whose energy regenerates on every difficulty - Cragmaw's
      does not and the Abomination's only moves when hit.

  6.3 TIMERS, seconds from pull
      ability                     script [SRV]      LW [LW]  DBM [DBM]
      Shockwave 272457            15.0, then 15.0   10.5     10
      Upheaval 259718             19.0, then 19.0   16.0     16.7
      Spawn Spore (259727)        7.0, then 7.0     -        -
      Festering Harvest 259732    100 energy       46.0     45.8
      Volatile Pods (H/M)         30.0, then 30.0   21.6     15.7
      The energy path is +3 every 3.0 s, which is 34 ticks and about
      102 s to the first harvest if nothing else adds energy [CALC].
      Both addons put it at 45 to 46 s, so retail's harvest arrives in
      less than half the script's time. LittleWigs' later Shockwave
      value is 10.6 and its later Upheaval values are 16.6 and 20.6
      (mythic plus only); DBM's mythic-plus Upheaval is 20.6.

  6.4 ASSIGNED-PLAYER MECHANICS AND EXACT TRIGGERS
      a) UPHEAVAL 259718 - THE ONE REAL ASSIGNMENT. Every 19.0 s the
         boss selects up to five random targets within 500 yd, removes
         every tank SPECIALISATION from that list (bear, protection
         warrior, protection paladin, blood DK, vengeance DH,
         brewmaster), then keeps two and casts 259718 on each. On aura
         removal the boss casts 274213 Upheaval on that player and
         strips Boundless Rot from every spore pod within 8.0 yd of
         THEM. So the two chosen players are clearing pods, and the
         tank is deliberately excluded.
      b) SHOCKWAVE 272457 - SELF-CAST every 15.0 s. On finish it takes
         every spore pod within 5.0 yd, drops the ones not in front of
         the boss, and strips Boundless Rot from anything inside the
         arc he is facing (isInFront with 3.14/4.0, i.e. a 90-degree
         wedge). A 5.0 yd radius makes this a melee-range effect, so
         the wedge decides which pods go quiet.
      c) SPAWN SPORE - every 7.0 s the boss picks up to three spore
         pod triggers 131597 within 500 yd that do NOT already carry
         259727 and applies it to them. The pods themselves are placed
         by DB and their positions are unverified.
      d) FESTERING HARVEST - at 100 energy, 1.0 s later the boss casts
         259732. On finish it strips 259727 from every pod within 500
         yd and applies 259714 Decaying Spore to every player in the
         instance except GMs - the loop skips player->IsGameMaster()
         and has no other filter, so tanks are included.
      e) VOLATILE PODS - heroic and mythic, every 30.0 s, six 139127
         triggers at the exact points in 3.1. Each lives 12.0 s and
         explodes at 10.0 s by casting 273300 six times at 60-degree
         steps around itself. The resulting area trigger applies 259714
         to any player who enters it.
      f) SOAK LISTS, KICK ORDER, TANK SWAPS: no kick, no swap. The soak
         list is (a): exactly two non-tanks per 19 s cycle, chosen at
         random, not assigned by the script.

  6.5 SAFE SPOTS, WITH z
      - The six volatile-pod points are exact and all six are between
        z 32.74 and z 33.96, i.e. within 0.63 yd of Zancha's centre z
        33.33 [SRV][CALC].
      - They form a ring 22.64 to 25.92 yd from the centre (3.4), in a
        ZRange of 20.0 to 40.0 and inside a 30.0 yd leash that kills
        players if the boss leaves it.
      - So the only circle this file can describe is the pod ring, and
        it is the ring to walk out of, not into: each pod covers six
        60-degree sectors around itself once it detonates.
      - Pod (131597) positions themselves are DB data and unverified,
        which means the safe spot for Shockwave and Spawn Spore cannot
        be given as a coordinate.

7. BOSS 4 - UNBOUND ABOMINATION 133007
==============================================================================

  7.1 SPAWN AND TANK POSITION. Spawn unverified. MDT anchor (295.1,
      -232.4) in MDT space, z unverified [MDT]. MDT health 5,994,261,
      level 120, force 0 [MDT]. The arena's own centre constant is
      (1199.420044, 1481.939941, -181.505997), which is also where

      TANK: unverified as a coordinate and largely irrelevant - the

      dies (7.4a), and every cast that matters is aimed at the raid
      or at the visages.
  7.2 PHASES: NONE BY HEALTH. The fight is gated by a BARRIER plus a
      kill counter, not by a percentage: 269185 Blood Barrier at pull,
      and six Blood Visage deaths end the encounter. No HealthBelowPct
      exists in boss_unbound_abomination.cpp.

  7.3 TIMERS, seconds from pull
      ability                     script [SRV]      LW [LW]  DBM [DBM]
      Vile Expulsion 269843       15.0, then 15.0   8.3      8.2
      Putrid Blood 269301         10.0, then 10.0   -        -
      Energy check                5.0, then 5.0     -        -
      Blood Visage (energy)       100 energy        -        22.3
      Cleansing Light 269310 (NPC) 20.0, then 20.0  18.0     18.2

      visage bar; the script has no timer for a visage at all, only an
      energy threshold.

  7.4 ASSIGNED-PLAYER MECHANICS AND EXACT TRIGGERS
      a) BLOOD BARRIER 269185 - applied in EnterCombat. While it is up,
         DamageTaken sets the damage to 0 and adds 1 energy PER DAMAGE
         EVENT, so the raid builds the bar by hitting an invulnerable
         boss. Energy is capped at 100.
      b) ENERGY CHECK, every 5.0 s. At exactly 100 it summons two
         137103 Blood Visages at (1228.46, 1459.84, -181.44) and
         (1168.01, 1499.57, -181.48) and zeroes the bar; at any other
         value it subtracts urand(5,10). So the bar only reaches 100 if
         the raid has landed enough hits inside the same 5 s window.
      c) SIX VISAGES END THE FIGHT. Each visage that dies calls
         ACTION_COUNT_VISAGE on the boss and casts 269692 Fatal Link on
         it. At the sixth, the boss removes its own Blood Barrier and
         then a player is told to kill it: player->Kill(me, false). The
         encounter ends at whatever health it had left, not at 0 - and
         because the barrier blocked every point of damage until then,
         that health is normally 100%.
      d) PUTRID BLOOD 269301 - every 10.0 s, applied to EVERY player,
         no target selection and no tank exemption.
      e) VILE EXPULSION 269843 - self-cast every 15.0 s. On finish it
         spawns five nodes in a straight line at (bossX + 2i, bossY,
         bossZ) for i = 0..4, i.e. an 8 yd span east of the boss made
         of five separate area triggers, each 5 yd wide by the spell's
         own comment.
      f) HEZREL'S THREE SUPPORT CASTS. Holy Bolt every 5.0 s at the
         boss, then Purge Corruption 7.0 s later at the nearest Blood
         Visage, in a permanent two-step loop. Cleansing Light every
         20.0 s on a random player, and it expires any Vile Expulsion
         area trigger within 10.0 yd of that player.
      g) ROTTING SPORE, heroic and mythic: every Vile Expulsion area
         trigger re-sets its own duration to 110.0 s after 30.0 s and
         spawns one 137458 Rotting Spore. The spore fixates a random

10. DISCREPANCIES AND TRAPS
==============================================================================

 10.1 NO SPAWN TABLE. Every boss spawn, tank position, safe spot and
      pull position in this file is unverified except the constants in
      section 3, and those are arena geometry, not placement.
 10.2 THE ENCOUNTER DATA IS ONE-BASED AND HAS EIGHT SLOTS FOR FOUR
      BOSSES (2.2). DATA_ELDER_LEAXA = 1, not 0. A script or DB row
      written for a zero-based dungeon is off by one here.
 10.3 BOTH 'CHEATER' CHECKS KILL PLAYERS FOR THE BOSS'S POSITION. Leaxa
      kills every player if the BOSS is 25.0 yd from her centre;
      Cragmaw does it at 80.0 yd from his. Neither measures a player.
      A tank that drags either boss out of its circle wipes the group.
      Leaxa's usable floor is therefore a 50 yd circle around
      (868.98, 1230.07, 56.30), which is small next to the 250 yd
      Creeping Rot line she casts inside it.
 10.4 BLOOD MIRROR PICKS FROM THREE POINTS IT CANNOT ADDRESS. The
      handler does switch (rand() % 3), which yields 0, 1 and 2, but
      the cases are 1, 2 and 3. So case 0 falls through with x and y
      UNINITIALISED and the effigy is summoned at whatever the stack
      held - roughly one cast in three. The reachable points are
      (875.113159, 1240.381958) and (879.703979, 1224.49646);
      (858.541931, 1221.745239) can never be used. Every one of them
      takes the BOSS'S z, not the platform's, so the effigy's z
      follows Leaxa wherever she is standing.
 10.5 CRAGMAW'S TANTRUM CANNOT HAPPEN ON NORMAL. Energy regen is
      scheduled only if the map is heroic or mythic, and Tantrum is
      the only spender, so on normal the boss never leaves his post.
      Both addons bar Tantrum at 45 s on every difficulty.
 10.6 CRAGMAW'S LARVAE SPAWN IN ONE QUADRANT. Charge uses
      (x + urand(2,10), y - urand(2,10)); Indigestion uses
      (x + urand(3,5), y - urand(3,7)). Positive x and negative y
      only, so the four Indigestion larvae always land south-east of
      the tank and the twelve Charge larvae always south-east of the
      boss. z is the BOSS's z in both cases, even for the tank box.
 10.7 ZANCHA'S HARVEST IS TWICE AS SLOW AS RETAIL'S. +3 energy every
      3.0 s is about 102 s to 100; both addons bar the harvest at 45 to
      46 s. The script's Upheaval is also 19 s against 16 to 17 s, and
      its Shockwave 15 s against 10 to 11 s.
 10.8 ZANCHA'S TANK FILTER IS A SPECIALISATION LIST, NOT A ROLE CHECK.
      checkSpec() excludes bear, protection warrior, protection
      paladin, blood DK, vengeance DH and brewmaster by spec id. A
      player tanking in any other spec is treated as a valid Upheaval
      target.
 10.9 SHOCKWAVE'S 5 YD RADIUS MAKES IT A MELEE EFFECT. It only strips
      Boundless Rot from pods within 5.0 yd of the boss and inside a
      90-degree wedge in front of him. The pods themselves are
      DB-placed 131597 and their positions are unverified, so whether
      any pod is ever in that wedge is unverified too.
 10.10 THE ABOMINATION DIES AT FULL HEALTH. Six visage deaths remove
       Blood Barrier and then a player kills the boss outright. Until
       the sixth, every point of damage is set to 0 by DamageTaken. A
       bot must count visages, not health.
 10.11 THE VISAGE KILL LOOP RUNS FOR EVERY PLAYER. DoAction calls
       player->Kill(me, false) once per living player in the map, so
       the boss is killed repeatedly in one tick, not once.
 10.12 HEZREL'S 'HOLY BOLT' IS AIMED AT THE BOSS, NOT AT A VISAGE.
       The loop variable is named visage but the entry it searches for
       is BOSS_UNBOUND_ABOMINATION; only Purge Corruption searches for
       NPC_BLOOD_VISAGE. The two casts alternate every 5.0 and 7.0 s.
 10.13 THE ROTTING SPORE FIXATES WITH 9999999999.9 THREAT and then
       follows its victim at zero distance. It has no leash and no
       duration in the script, so it only stops when killed or when
       the group leaves the arena band.
 10.14 ADDON IDS THAT DO NOT EXIST IN THIS CORE: 265091 Gift of Ghuun,
       278755 Harrowing Despair and 413044 Dark Echoes are barred by
       DBM's trash file and appear in no SmartAI row here. LittleWigs
       bars Blood Bolt at 15.4 s, a retail cadence this core never
       reaches with its 4 s timer.
 10.15 THE ROSTER AND THE SCRIPT DO NOT COVER THE SAME CREATURES. Six
       SmartAI entries are not on MDT's roster at all (132051 Blood
       Tick, 134701 Blood Effigy, 138740 Musashitake, 138338 Reanimated
       Guardian, 140593 Restless Horror, 139194 Rotmaw), and MDT
       carries six records this dungeon does not use: the four
       Horrific Vision bosses 161124, 161241, 161243 and 161244, plus
       the Emissaries 155432 and 155434.
 10.16 THE DEFILER HAS TWO ENTRIES AND ONLY ONE IS USED. the_underrot.h
       declares NPC_BLOODSWORN_DEFILER = 144306, but no line in any
       file references that constant; the creature that exists with
       the name is 133912, which is what the SmartAI file covers and
       what MDT places six times. Treat 144306 as a dead id.

11. WHAT IS NOT IN THIS FILE, AND WHY
==============================================================================

 11.1 Boss spawn coordinates and tank coordinates are unverified for
      all four encounters. No creature row with coordinates for map
      1841 is public, and the scripts carry ten Position constants,
      none of which is a boss placement.
 11.2 Pull positions with z are unverified. MDT's clone layout is in
      map space with no z; 8.5 says what it can and cannot be used
      for.
 11.3 Line of sight is unverified. The instance script handles two
      game objects by id and carries no position for either, so there
      is nothing to anchor a LOS statement to.
 11.4 Spore pod 131597 and Spirit Drain Totem 135169 positions are
      unverified - they are DB placements with no row in any source
      read here.
 11.5 No radius, duration or damage figure came from a client table.
      The 5 yd Shockwave radius, the 8 yd Upheaval radius, the 10 yd
      Cleansing Light radius, the 25/30/80/90 yd leash numbers and the
      250 yd Creeping Rot length are script literals and nothing more.
 11.6 Item ids are not quoted. The only Underrot world SQL read here
      is the SmartAI file, which carries no item data.
 11.7 Nothing here came from a video, a guide site or a forum post.
