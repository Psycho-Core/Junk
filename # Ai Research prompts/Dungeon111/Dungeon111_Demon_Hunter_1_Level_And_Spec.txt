---------------------------------------------------

Why Vengeance (Spec ID 581) Beats Havoc (Spec ID 577) for a Companion Dungeon Booster:
1) Survives Stuns and Whole-Room Pulls Without Gear Dependency:
   - Vengeance has passive Demonic Wards (Spell ID 203513: -15% all damage taken, +65% Stamina, +100% bonus Armor from gear [buffed in Patch 8.2.0], and melee crit immunity against dungeon mobs/bosses), Leather Specialization (Spell ID 226359: +5% Stamina) + tank Stamina multiplier (Spell ID 212613), 2 off-GCD charges of Demon Spikes (Spell ID 203720, Buff 203819: 0 Pain cost, +60% of Agility as Armor scaled by Mastery: Fel Blood Spell ID 203747, plus +15% Parry in 8.0.1-8.3.7), Fiery Brand (Spell ID 204021, Debuff 207744: -40% enemy damage dealt), Metamorphosis (Spell ID 187827: +50% max & current HP, +200% bonus Armor, and +20 Pain / +1 Lesser Soul Fragment on Shear/Fracture [buffed in 8.2.0]), and automatic cheat-death Last Resort (Talent ID 22543, Spell ID 209258).
   - By contrast, Havoc's sustain relies on Demonic (Talent ID 21900, Spell ID 213410) + Soul Rending (Talent ID 21863, Spell ID 204909: +5% passive Leech and +25% additional Leech while in Metamorphosis in 8.0.1-8.3.7) + 1-sec Blade Dance dodge windows, which only achieves high uptime after farming Legion Legendary helm Raddon's Cascading Eyes (Item ID 137061). Even geared, Havoc lacks crit immunity, lacks bonus Armor (Havoc Demonic Wards Spell ID 278386 is 10% magic DR only), and dies immediately if chain-stunned or interrupted during Eye Beam (Spell ID 198013) in multi-pack Freehold/Motherlode pulls.
2) Multi-Pack AoE Damage That Fuels Its Own Healing:
   - Immolation Aura (Spell ID 178740) + Fallout (Talent ID 22766, Spell ID 227174) shatters up to 5 Lesser Soul Fragments instantly on pull; Infernal Strike (Spell ID 189110) + Abyssal Strike (Talent ID 22502, Spell ID 207550) + Flame Crash (Talent ID 22324, Spell ID 227322) leaps 40 yds every 12s while dropping a free Sigil of Flame (Spell ID 204596, Damage 204598); Spirit Bomb (Talent ID 22513, Spell ID 247454) explodes on nearby enemies (soft-capped at 20 targets in 8.3.7) and applies Frailty (Spell ID 247456), healing the DH for 10% of ALL damage dealt to every afflicted enemy for 20s; Soul Cleave (Spell ID 228477, 30 Pain) cleaves up to 5 front targets while healing and consuming up to 2 Soul Fragments; Chaos Brand (Spell ID 255260) increases all Fire/magic damage taken by 5% on every hit mob.
3) Tank Threat Lock & Pack-Stacking Tools to Protect the Low-Level Player:
   - Increased Threat (Spell ID 189926, +350% threat / 4.5x total threat) plus 3-sec cooldown high-threat Throw Glaive (Spell ID 204157, 3-target ricochet) locks entire rooms onto the bot while running, whereas Havoc generates 1.0x DPS threat with a 9-sec Throw Glaive (Spell ID 185123).
   - Sigil of Chains (Talent ID 22511, Spell ID 202138) grips and slows whole packs onto one spot; Sigil of Silence (Spell ID 202137) silences ranged caster packs for 6s so they run into melee; Sigil of Misery (Spell ID 207684) AoE-disorients dangerous casts; Vengeance also queues as Tank for instant Random Dungeon Finder pops across all leveling brackets.
