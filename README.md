# BfA 8.3.7 research prompts, second round (2026-10-29)

Why a second round: the first round could not give world coordinates, scenario stage data or the true opcode numbers, because it only read guide pages. These prompts name the kinds of source that do have them (database rows of published Battle for Azeroth cores, parsed sniffs, the opcode tables of the packet parser) and ask for NOT FOUND instead of guesses. Send one file per message; the answer is a descriptive .txt, saved next to the prompt in a `*_completed` folder.

Suggested order: Scoreboard first (one file; it settles the open scoreboard issue), then Economy, then Positions, then Routes, Warfronts last.

- Positions/01 and 02: where the Awakened spires stand (world coordinates), Positions/03: the Beguiling emissaries.
- Routes/01 to 03: the boss order, the doors and the path points of the dungeons, for a dungeon clear mode.
- Warfronts/01 to 04: spawn positions and paths of the four attacks, 05: scripts, economy and contribution.
- Scoreboard/01: the opcodes of build 35662 against ours.
- Economy/01 to 03: Vashreen's vendor, Horrific Visions rewards, MOTHER's corruptions; the numbers you supplied are in Economy/Titan_Residuum_Economy_supplied.txt.

What the answers unlock: Awakened and Beguiling spawns, `.dc` dungeon clear, playable warfronts, the scoreboard window, and the Residuum, Echoes and Corruption shops.
