=== 0. HOW TO READ / ORIENTATION ===
Facing values are reproduced exactly as stored (world_safe_locs rows:
same degrees-like convention as the other files; script floats: as
written). None of them was converted.
No readable source assigns north/south/east/west to map 727's axes; this
file therefore makes NO coordinate-compass claims. The words "East" and
"North" below are entity names used by the script itself (East switch,
North switch) - they are quoted as names, not derived directions.
Depot cluster band (recomputed from the four script BgSSMDepotPos
positions): x 564.8048 - 896.7936, y 25.29027 - 502.3111,
z 298.2867 - 364.1431.
Relative position note (raw, no compass): the Alliance start row has a
higher x than the Horde start row (851.575 vs 630.17).
Route legs are straight-line distances between sourced landmarks. They
are NOT walkable-path measurements: no pathing/navmesh source for map 727
could be read (unverified), and the minecart rail waypoints are not in
any readable source either.

=== 5. GRAVEYARDS ===
Two rows only - each faction's start row doubles as its graveyard
  (script enum SSM_GRAVEYARD_MAIN_ALLIANCE = 4062,
  SSM_GRAVEYARD_MAIN_HORDE = 4061; verbatim rows in section 2).
The graveyard rule (script GetClosestGraveYard, exact logic): always the
  player's own team's main row - there is no third party, no nearest-
  pair choice and no per-point graveyard. warcraft.wiki confirms:
  "only a single graveyard for each faction, located safely within that
  faction's raised starting area".
Which graveyard belongs to which point: none - carts and depots own no
  graveyards in either readable source.
Spirit guides are spawned at both rows at setup (script AddSpiritGuide),
  using the Battleground base-class spirit creatures 13116 (Alliance) /
  13117 (Horde). Start-to-own-graveyard distance: 0 yd (same row).
Respawn walk to the depots equals the start routes in section 4.
