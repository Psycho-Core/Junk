BATTLE FOR AZEROTH 8.3.7 (BUILD 35662) - SKINNING GATHERING FOR A SERVER-SIDE COMPANION
==========================================================================================

Scope: how a computer-controlled character (no client) skins with Skinning on a
TrinityCore-based 8.3.7 server. Every id below was read from a source this week;
anything without a readable source says "unverified" instead of a guess.

2. THE SPELL IDS THAT GATHER
----------------------------
  The single on-corpse cast at every expansion: 8613 "Skinning".
    Effect #1: Skin Mob, value 1. Effect #2: Learn Skill Skinning 393,
    value 1. Range 5 yards (Interact). Cost none. GCD 0 seconds.
    Flags: Is Ability, Can be used while mounted, Generates no threat,
    Suppress Caster Procs, Do Not Display Range, Don't close loot window.
    (wowhead spell=8613, read 2026-10-25.)
  There are NO per-expansion on-corpse spells: the 2658xx spells in section 1
  are instant self learns, not casts on the corpse.
  Rank spells 8617/8618/10768/32678/50305/74522/102216 are the pre-8.0 rank
  variants of the same skinning action (wowhead "Other ranks" of 8613).
  The official instructions are right-click the corpse (2019 Blizzard
  game-guide capture, section 10); no spell or item substitutes for the
  cast itself.

3. HOW LONG A GATHER TAKES
--------------------------
  Base cast time: 1.5 seconds, range 5 yards, cost none, GCD 0. Verified
  three ways read 2026-10-25: wowhead spell 8613 header "1.5 sec cast" and
  details row "Cast time 1.5 seconds"; the wow-professions BfA guide says the
  glove enchants bring "skinning time down from 1.5 seconds to 0.5"; the
  Legion guide says the same of its enchant; the vanilla guide says Darkmoon
  Firewater "reduces your skinning time from 1.5 seconds to 0.5".
  Speed items/enchants (all 1.5 -> 0.5 seconds per the guides):
    Enchant Gloves - Kul Tiran Skinning item 153434,
    Enchant Gloves - Zandalari Skinning item 159467 (BfA guide),
    Enchant Gloves - Legion Skinning item 128560 (Legion guide),
    Darkmoon Firewater item 124671 (vanilla guide).
  Mounted: the current 8613 page carries the "Can be used while mounted"
  flag; no 8.3.7-era capture of 8613 was read, so baseline mounted skinning
  on 8.3.7 is unverified - test before relying on it.
  Knife: wiki Skinning Knife page - item 7005, ilvl 2 Skinning Tool,
  "Requires Skinning (1)", sold by skinning supply vendors. History from the
  same page's patch notes: durability added 4.0.3a; patch 5.0.4 "No longer
  required to skin. Now provides +10 Skinning while equipped or in
  inventory"; patch 10.0.2 moved it from main hand to the profession-tool
  slot. The page's current equip line reads "+4 Skinning Skill". Whether the
  BfA-era bonus was +10 or +4 is unverified; the 2019 official page still
  instructs "a skinning knife in your inventory". The wiki equipment box
  also lists the Gnomish Army Knife (WotLK) under skinning tools - its exact
  function as a knife substitute is unverified here.

4. SKILL NEEDED PER CREATURE (AND WHAT DROPS)
---------------------------------------------
4.1 Who is skinnable
  Skinnable corpses are beasts, dragonkin, silithids, some nerubians, demon
  beasts and, very rarely, humanoids. Not every beast qualifies - most birds
  cannot be skinned - and a corpse must be looted empty before it can be
  skinned. Critters stopped being skinnable in patch 3.2.0 (wiki patch list,
  read 2026-10-25). The 2019 official guide: approach a slain beast "along
  with some dragonkin or insectoid foes", knife in inventory, right-click;
  you do not need to have killed it yourself.
4.2 Required skill as a function of creature level
  Skinning is the one gathering profession whose requirement is not a
  per-node value: TrinityCore computes it in Spell::EffectSkinning from the
  creature's level with these bands (BfA_8.3.7_party_features.txt 4.2,
  read 2026-10-21 from TrinityCore master and the 2020 Skinning article):

    Creature level    Required skill      Examples
    1-10              1                   1 -> 1, 10 -> 1
    11-19             (level - 10) x 10   11 -> 10, 19 -> 90
    20-73             level x 5           20 -> 100, 60 -> 300, 73 -> 365
    74-79             level x 10 - 365    74 -> 375, 79 -> 425
    80-84             level x 5 + 35      80 -> 435, 84 -> 455
    85-87             level x 15 - 805    85 -> 470, 87 -> 500
    88-92             (level - 62) x 20   88 -> 520, 92 -> 600
    93-104            level x 5 + 175     93 -> 640, 104 -> 695
    105-107           level x 15 - 905    105 -> 670, 107 -> 700
    108-112           (level - 72) x 20   108 -> 720, 112 -> 800
    113-122           (level - 32) x 10   113 -> 810, 120 -> 880
    123 and up        900                 flat cap

  Read the table literally: the bands are not monotonic (level 104 needs 695,
  level 105 needs 670). Use the formulas, never an interpolation. The 2020
  article's own 74-87 numbers differ from the code (470 at level 84, 530 at
  level 87 where the code gives 455 and 500); the code is what the server
  computes and is treated as authoritative. TrinityCore resolves which skill
  line to check from the creature's ContentTuning expansion id
  (Player::GetProfessionSkillForExp), so a level 120 corpse is judged against
  the BfA line 2557, not the 1-300 Classic one (party_features 4.1).
  Two standing cautions (party_features 4.2 and 5):
    - TrinityCore uses the value only to pick the skill-up band;
      EffectSkinning does not refuse the cast when skill is too low - it
      fills the loot and rolls the skill-up. On a stock server the "Requires
      Skinning (X)" refusal is client-side. Whether an 8.3.7 fork enforces
      it server-side is unverified.
    - The value is on the base 1-300 style scale; the BfA line caps at
      150-175, so the level 108-122 rows cannot be what a BfA character
      sees. The conversion to the BfA scale is unverified; what is verified
      is that BfA content is gated on the BfA line.
  The vanilla guide adds the play-side view: "You can skin any mobs with
  Skinning skill one, but the type of leather you get is determined by the
  mobs level and your skinning skill." Colour words on the corpse (wiki,
  Advancing as a Skinner): red = not high enough skill to skin, orange =
  always a point, yellow = probably, green = probably not, grey = never.

5. HOW THE SKILL RISES (SERVER RULES)
--------------------------------------
  Gathering uses one shared routine (Player::UpdateGatherSkill); the colour
  of the corpse selects the chance (BfA_8.3.7_party_features.txt 4.6):

    Colour  Corpse state   Chance  TrinityCore setting
    Red     skill too low   n/a    -
    Orange  red + 0        100%    SkillChance.Orange = 100
    Yellow  red + 30        75%    SkillChance.Yellow = 75
    Green   red + 60        25%    SkillChance.Green = 25
    Grey    red + 90         0%    SkillChance.Grey = 0

  - Bands are computed, not stored: red = the corpse's required skill from
    section 4.2, yellow = red + 30, green = yellow + 30, grey = green + 30.
  - One point per success (SkillGain.Gathering = 1). Skinning doubles the
    chance against elite creatures; the multiplier is 2 for elites and 1
    otherwise.
  - Mining and skinning decay: SkillChance.MiningSteps and
    SkillChance.SkinningSteps right-shift the chance by skill / steps,
    halving it once per steps skill points; setting either to 0 disables the
    decay.
  - The cap is the rank's: TrinityCore refuses to raise a skill once it
    reaches the learned rank maximum (150 or 175 for BfA - unverified which,
    section 1).
  - Hotfix 2011-06-01 (wiki patch list): "Players can no longer continue
    gaining Skinning skill points using low-level creatures below the
    intended skill threshold."
  - Patch 3.1.0 (wiki patch list): "You can no longer fail when Mining,
    Herbing, and Skinning." - the 1.5-second cast does not fizzle.
  - Patch 8.0.1 (wiki patch list): each expansion got a separate skill bar
    with smaller caps instead of one gigantic bar.
  - The vanilla guide reports a current-retail quirk: some players see
    skinning stop granting points at 250 or 285 on the Classic 1-300 bar
    and "Level 40 seems to be required to max out vanilla Skinning" - guide
    claim, server-side cause unverified.

6. HOW CORPSES "RESPAWN"
------------------------
  Skinners have no gameobjects at all: there are no herb or ore nodes to
  pool or respawn - every target is a creature corpse, so "respawn" is the
  mob's respawn plus the corpse's lifetime.
  Corpse lifetime rules:
    - Loot it empty first, then skin (wiki notes and 2019 official page).
    - If another player starts skinning the mob, the corpse is "tapped" and
      nobody else can skin it (wiki notes).
    - Corpses despawn if you wait too long: the Northrend guide warns to
      stop and skin twice at Ruby Sanctum "because the corpses might start
      despawning before you can skin them"; the Cataclysm guide says pull
      Firelands in two pulls "else you won't be able to skin them fast
      enough, and the corpses will start despawning."
    - One skin per corpse: the skin empties the skinning loot; the 8613
      flag "Don't close loot window" keeps the window open during the
      exchange (wowhead 8613).
  Observed respawn rates for the farmed mobs (guide observations, not DB
  values): Armored Battleboars in Mulgore respawn "extremely quickly"
  (vanilla guide); Wetlands fast enough that two new Ebon Slavehunters
  appear by the time the second skin finishes; Tamed Clefthoof in Nagrand
  spawn "instantly" one or two at a time when the pack is fully killed
  (Draenor guide, coordinates below); Frost Wolves in Frostfire Ridge "fast
  respawn rate, probably around 30 seconds"; Moonshell Crawlers "really fast
  - you will never run out of them"; Skyrange packs "always at least one
  pack up" (Pandaria).
  Instance routes (Karazhan, Ruby Sanctum, Firelands) reset with the
  "Reset all instances" button, which respawns every mob in it; do not kill
  the listed bosses or the reset locks.
  No source read gives numeric per-mob respawn times: they live in your
  world database rows; the client build 35662 ships no spawn rows,
  coordinates or respawn times (BfA_8.3.7_party_features.txt 4.7) - all
  exact intervals unverified from client sources.

9. WHAT A SERVER-SIDE CHARACTER (NO CLIENT) CANNOT DO
-----------------------------------------------------
  1. Cannot see the client pointer cues: the knife-shaped cursor near a
     skinnable corpse and the glow are client rendering (official 2019
     instructions); the companion must decide skinnability from your DB.
  2. Cannot use a tracking spell: none exists (section 1) - there is no
     "Find Corpses" overlay to follow; route from guide coordinates and DB
     spawns instead.
  3. Cannot receive the right-click: no CMSG arrives; the bot must start
     the 1.5-second 8613 cast itself, corpse guid as target, inside the
     5-yard interact range.
  4. Cannot see "loot empty": the wiki requires every item looted before
     the skin. The companion must read the corpse's loot itself first; what
     a fork does when the rule is violated is unverified (section 4.2).
  5. Cannot watch the loot window: "Don't close loot window" is a client
     flag; the companion must collect the skinning_loot_template output
     itself.
  6. Cannot know what will drop: which entry yields which leather, hide,
     scale or the five BfA materials is skinning_loot_template keyed by
     SkinLootID - server data, not in build 35662 (section 4.3).
  7. Cannot trust the colour refusal: on TrinityCore master EffectSkinning
     never refuses a too-low-skill cast; whether an 8.3.7 fork does is
     unverified (section 4.2). Similarly the level-band-to-BfA-scale
     conversion and the skill at which a level 110-120 BfA corpse becomes
     skinnable are recorded unverified (party_features 5).
  8. Cannot re-skin or contest a corpse: one skin empties it, and a corpse
     another player already started skinning is tapped (section 6).
  9. Cannot plan around corpse timing from client data: despawn-before-
     skin losses are real (guides), and every exact respawn interval is
     world-DB only (section 6).
 10. Cannot count on the knife bonus: item 7005 must be present for the
     equip bonus, its BfA-era value is unverified (+10 at 5.0.4 vs +4 on
     the current page), and pre-MoP eras treated the knife as required
     (section 3).
 11. Cannot exceed the cap or read the odds: the rank maximum stops raises
     (150 or 175 for BfA - unverified which), the elite x2 multiplier and
     SkinningSteps decay run server-side (section 5), and companion skill
     accounting must read the skill line directly.
