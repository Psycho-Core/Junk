2. CHEAPEST WAY TO GET TO EXACTLY 111 AND KEEP IT THERE
-------------------------------------------------------
Cheapest Normal In-Game Method (Total Cost: 10 Gold = 100,000 Copper):
1) Create an Allied Race or Pandaren Death Knight at level 58 (skips the 55->58 Scarlet Enclave chain), OR create a Core Race Death Knight at level 55 and finish the Scarlet Enclave chain to ~58 (earns >20 gold along the way).
2) Level to 110 using free quest rewards (or already-owned Heirlooms), pick up Heart of Azeroth (Item ID 158075) at 110 for free, earn 537,730 XP to hit level 111, and stop immediately near 0% into level 111 (keeps personal-scaled BfA Normal dungeon mobs scaled to 110-111).
3) Pay 10 gold (100,000 copper) to lock XP:
   - Alliance: Behsten <Experience Eliminator>, Creature Entry 35365, Stormwind Keep, Stormwind City, Map ID 0, 2D Zone Coords (87.6, 36.0), World Coords (0, x, y, z): unverified.
   - Horde: Slahtz <Experience Eliminator>, Creature Entry 35364, Hall of the Brave (third floor), Valley of Honor, Orgrimmar, Map ID 1, 2D Zone Coords: unverified, World Coords (1, x, y, z): unverified.
4) Apply free Runeforging (Spell ID 53428 -> Rune of the Fallen Crusader Spell ID 53344) in Acherus via Death Gate (Spell ID 50977) instead of paid weapon enchants.

TrinityCore 35662 Companion Bot Setup & Critical XP-Lock Behavior (0 Gold):
- Spawn or level the companion directly to 111 (ensure Death Gate Spell ID 50977 is learned if created on Map ID 609) and set PLAYER_FLAGS_NO_XP_GAIN (0x02000000) directly on the character (or toggle via Behsten 35365 / Slahtz 35364).
- Retail vs. Stock TrinityCore Party XP Difference:
  * Retail 8.2.0-8.3.7: Locking XP applies Experience Eliminated (Spell ID 306715) on the Death Knight and projects Experience Eliminated (Spell ID 206662, 300-yard aura reducing kill and quest XP by 95%) onto manually grouped party members.
  * Stock TrinityCore 35662: Sets PLAYER_FLAGS_NO_XP_GAIN (0x02000000), causing Player::GiveXP to return early with zero XP gain for the Death Knight while NOT applying Spell ID 306715 or Spell ID 206662. The companion stays locked at 111 forever and the grouped low-level player receives 100% normal XP. Do not custom-script Spell ID 206662 onto companion boosters.
- Why Lock at 111 Specifically:
  * Enters the 110-120 BfA Normal personal-scaling bracket (Freehold Map ID 1754) at peak combat-rating scaling before level 112-120 secondary-stat decay.
  * Equips cheap BfA crafted gear (Requires Level 111), Heart of Azeroth (Item ID 158075) + 3 BfA Azerite pieces, AND 2 Legion Legendaries simultaneously (Legion Legendaries deactivate at level 116).
  * Keeps gray-mob threshold at 101 (111 - 10), so Legion Normal dungeon mobs (scaled to 110) remain green/full-XP.


3. BEST SPECIALIZATION FOR DUNGEON BOOSTING AND WHY
---------------------------------------------------
Best Specialization:
- Blood (ChrSpecialization ID 250, Role: Tank, Spec Passive: Blood Death Knight Spell ID 137008).
- Other Death Knight Specs (Not Selected): Frost (Spec ID 251, Passive Spell ID 137006) and Unholy (Spec ID 252, Passive Spell ID 137007).

Why Blood Beats Frost and Unholy for Multi-Pack Dungeon Boosting:
1) Self-Healing Scales Up With Pull Size: Death Strike (Spell ID 49998, Heal Spell ID 45470) heals for 25% of all damage taken in the preceding 5 seconds (minimum 7% max HP) and Mastery: Blood Shield (Spell ID 77513, Shield Spell ID 77535) creates a physical absorb shield from that heal. Pulling 4-6 elite packs increases incoming damage and therefore increases Death Strike healing, whereas Frost and Unholy lack Blood Shield, Bone Shield (Spell ID 195181, -16% damage taken), Veteran of the Third/Fourth War (+60% Stamina vs +10%), and Vampiric Blood (Spell ID 55233).
2) Instant Zero-Ramp Multi-Pack AoE + Self-Heal Cooldowns: Two charges of instant PBAoE Blood Boil (Spell ID 50842) spread Blood Plague (Spell ID 55078) and stack Hemostasis (Spell ID 273946, up to +40% next Death Strike damage/healing); Death and Decay (Spell ID 43265) lets Heart Strike (Spell ID 206930) cleave 5 targets and generate massive Runic Power via Heartbreaker (Spell ID 221536); Bonestorm (Spell ID 194844) deals heavy Shadow AoE every 1 sec while healing 3% max HP per enemy hit (up to 15% max HP/sec). Unholy requires Festering Wound ramp per pack, and Frost cannot survive 20-mob elite pulls under BfA or Party Sync scaling.
3) Total Threat Control & Mass Mob Stacking: Tank threat modifier keeps all enemies off the low-level player. Gorefiend's Grasp (Spell ID 108199) pulls every enemy within 15 yards onto one spot for instant AoE and interrupts, backed by Death Grip (Spell ID 49576) and ranged Death's Caress (Spell ID 195292).
4) Built-In Immunities Against Dungeon Slowdowns: Death's Advance (Spell ID 48265) grants knockback and forced-movement immunity; Icebound Fortitude (Spell ID 48792) breaks/prevents stuns; Anti-Magic Shell (Spell ID 48707) blocks healing-reduction and CC magic debuffs; Raise Ally (Spell ID 61999) combat-resurrects the low-level player if needed.
