3. CHEAPEST ROUTE 1 TO THE CAP OF EACH LINE
-------------------------------------------
Source for every step: the wow-professions guide named per line (full
URLs in section 10). Counts are the guide's own cast counts; yellow/green
warnings mean more materials than the printed exact math - the shopping
list is the authority. Milling is the shared opening of most lines
(section 3.0).

3.0 Milling as a skill source (applies to 1-25 of most lines):
Milling spell 51005 ("Crush 5 herbs to create pigments for making inks.
This will destroy the herbs in the process", 1 sec cast, Effect: Milling
Value 5, "Target must be own item", Cooldown n/a). Requirements (wowpedia
Milling page): Level 5 + Inscription (1). Five of any listed herb make
2-4 common pigments and may produce 1-3 uncommon pigments (warcraft.wiki
Inscription_ingredients). The guides state "milling gives skill points up
to 25" (vanilla, Outland, Northrend, Pandaria, Draenor, Legion, BfA
guides all open by milling their herb list to 25). Mass Milling recipes
mill 20 herbs at once: Legion unlocks them via quest "Mass Milling
Techniques" 39954 (section 3.7); BfA "you will unlock Mass Mill at 50,
which will give skill points up to 80" and "Mass Mill Zin'anthid" 298927
is learned at 155 (4-5 points per mass mill); the Legion guide warns
"DO NOT USE MASS MILL YET, IT WON'T GIVE YOU SKILL POINTS" before 25.

7. WHAT THE CORE MUST DO FOR A CRAFT TO SUCCEED
-----------------------------------------------
Verified against TrinityCore master fetched this week (blobless sparse
clone; paths under src/server/game/ and src/server/scripts/). Line
numbers are from this fetch; upstream moves - section 9 item 15 records
the drift against the earlier files.
a) Learn press: NPCHandler.cpp 97 HandleTrainerListOpcode -> 112
   SendTrainerList -> 130 HandleTrainerBuySpellOpcode -> 145 interaction
   guard -> 155 trainer->TeachSpell; Trainer.cpp 76 TeachSpell -> 79
   CanTeachSpell -> 149 CanTeachSpell body: state must be Available (172
   GetSpellState: known check, race/class, skill gate 182-184,
   prerequisite spells 185-187, level 189-191, rank-chain logic), free
   primary profession point (156/165), money at 100-106 with reputation
   discount 98; then IsCastable -> CastSpell or LearnSpell. This is how
   45357, the eight expansion mains (264494, 264496, 264498, 264500,
   264502, 264504, 264506, 264508/265809) and their wrappers enter the
   character; the Draenor scroll goes item 111923 -> Learning 161789 ->
   wrapper 264505, and the Legion wrapper 264507 arrives through the
   quest-reward learn path.
b) Crafting a product (the common case): recipes are Effect Create Item
   (sampled pages print Effect: Create Item, e.g. Moonglow Ink 52843
   "Create Item Moonglow Ink", Ultramarine 264776, Maroon 298929). TC
   path: Spell::cast takes reagents at Spell.cpp 3872/3877
   TakeReagents() (definition 5600); DoCreateItem SpellEffects.cpp 1383
   handles the item grant, reports inventory full at 1440
   (EQUIP_ERR_INV_FULL || EQUIP_ERR_ITEM_MAX_COUNT -> SendEquipError),
   and grants skill at 1469 (`if (!m_CastItem) player->
   UpdateCraftSkill(m_spellInfo);`).
c) Variable-yield crafts: none of the routed steps print a variable
   yield - every count is fixed (splits/odds live in milling instead).
   The generic mechanism still exists for anything that needs it:
   SPELL_EFFECT_CREATE_ITEM_2 (effect 157, table line 249) with
   IsLootCrafting rolls from LootTemplates_Spell (EffectCreateItem2
   SpellEffects.cpp 1482, 1495-1497 AutoStoreLoot, second AutoStoreLoot
   at 1522); item-cast crafts grant skill through Spell.cpp 3863
   (SPELL_ATTR9_ITEM_CAST_GRANTS_SKILL_GAIN).
d) MILLING (this profession's signature effect): spell 51005 carries
   SPELL_EFFECT_MILLING (effect 158, table SpellEffects.cpp 250,
   implicit target ITEM at SpellInfo.cpp 1120). CheckCast block
   Spell.cpp 7836-7866 returns, in order: no target -> failed
   CANT_BE_MILLED; target without ITEM_FLAG_IS_MILLABLE -> failed
   CANT_BE_MILLED; item owned by someone else (trade slot) -> failed
   CANT_BE_MILLED; skill gate `item RequiredSkillRank > player
   GetSkillValue(SKILL_INSCRIPTION)` -> failed LOW_CASTLEVEL (this is
   the only cast-time recipe-like skill gate in these routes); stack of
   fewer than 5 -> failed NEED_MORE_ITEMS (fills the need-items counters
   with the herb entry and 5); loot template missing -> failed
   CANT_BE_MILLED. EffectMilling SpellEffects.cpp 4641-4666: target-only
   handle mode, re-check millable flag (4651) and count >= 5 (4654);
   world config CONFIG_SKILL_MILLING (4656) gates the skill grant:
   GetPureSkillValue + herb RequiredSkillRank -> UpdateGatherSkill
   (4658-4660); then builds LOOT_MILLING from LootTemplates_Milling
   keyed by the target item entry (4663-4664) and SendLoot (4665).
   Consumption happens on loot: LootHandler.cpp 348-361 destroys
   exactly 5 items from the stack ("destroy only 5 items from stack in
   case prospecting and milling", capped at 5 for cheat cases). IMPORTANT
   SERVER CONFIG: World.cpp 630 registers "SkillChance.Milling" with
   DefaultValue false (World.h 124 CONFIG_SKILL_MILLING) - on a default
   TC config milling yields pigments but grants no inscription skill;
   the core must set SkillChance.Milling = true for the guides' "milling
   to 25" opening to work.
e) Skill-up math: Player::UpdateCraftSkill Player.cpp 5410, early-out
   SPELL_ATTR1_NO_SKILL_INCREASE 5412, SkillLineAbility lookup,
   discovery branch MECHANIC_DISCOVERY 5427 (research spells carry a
   Script Effect alongside their Create Tradeskill Item - spell 165467
   prints both effects and "Teaches (4)" glyph rows), gain =
   NumSkillUps x CONFIG_SKILL_GAIN_CRAFTING 5433, chance via
   SkillGainChance over the line's thresholds -> UpdateSkillPro
   5435-5437. Other call sites: DoCreateItem 1469, EffectCreateItem2
   1499. Wiki colour rules: orange always, yellow probably, green
   probably not, grey never; red = not high enough skill to learn the
   recipe.
f) Learning recipes beyond the profession lines: trainer Taught-by paths
   (section 2); quest rewards (Legion 39847 -> 264507); the Draenor
   scroll chain (111923 -> 161789); technique items learned by use
   (Technique: Origami Beetle 65651 drop, Technique: Volatile Crystal
