=== ARENA QUEUE PROTOCOL - BFA 8.3.7 (TRINITYCORE) ===

=== 1. CLIENT PACKETS ===

CMSG_BATTLEMASTER_HELLO (0x3D018F)
  Request battleground list from battlemaster NPC
  Fields: Unit GUID (battlemaster)

CMSG_BATTLEMASTER_JOIN (0x3E00BD) - Rated BG / Normal BG
  Fields:
    Array<uint64> QueueIDs - packed BattlegroundQueueTypeId
      (BattlemasterListId, Type, Rated, TeamSize)
    uint8 Roles - player roles bitmask (TANK=1, HEALER=2, DAMAGE=4)
    array<int32, 2> BlacklistMap - blacklisted map IDs

CMSG_BATTLEMASTER_JOIN_ARENA (0x3E00BE) - Rated Arena
  Fields:
    uint8 TeamSizeIndex - arena slot index (0=2v2, 1=3v3, 2=5v5)
    uint8 Roles - player roles bitmask (TANK=1, HEALER=2, DAMAGE=4)

CMSG_BATTLEMASTER_JOIN_SKIRMISH (0x3E00C1) - Arena Skirmish (unrated)
  Fields: (same as JOIN_ARENA in modern TrinityCore)
    uint8 TeamSizeIndex
    uint8 Roles

CMSG_BATTLEFIELD_PORT (0x3E00C7) - Accept/Decline queue pop
  Fields:
    RideTicket Ticket { Id, Type, Time }
    bool AcceptedInvite

CMSG_BATTLEFIELD_LEAVE (0x3D001F) - Leave queue or battleground
  No fields

CMSG_REQUEST_BATTLEFIELD_STATUS (0x...) - Request queue status update
  No fields

=== 2. SERVER HANDLERS (WorldSession in BattleGroundHandler.cpp) ===

HandleBattlemasterHelloOpcode()
  - Validates NPC interaction (UNIT_NPC_FLAG_BATTLEMASTER)
  - Calls sBattlegroundMgr->SendBattlegroundList()

HandleBattlemasterJoinOpcode(BattlemasterJoin)
  1. Decode QueueIDs[0] to BattlegroundQueueTypeId
  2. Validate queue ID (IsValidQueueId)
  3. Get bracket entry by player level
  4. Check player not in BG, not deserter, not in LFG, queue slots available
  5. Determine team (mercenary contracts for unrated BG)
  6. If solo: bgQueue.AddGroup(player, nullptr, team, bracketEntry, false, 0)
  7. If group: leader only; grp->CanJoinBattlegroundQueue() validation
  8. Add all members to queue, send SMSG_BATTLEFIELD_STATUS_QUEUED
  9. ScheduleQueueUpdate(0, bgQueueTypeId, bracket_id)

HandleBattlemasterJoinArena(BattlemasterJoinArena) - Rated Arena
  1. Ignore if already in BG
  2. Convert TeamSizeIndex to arena type
     (GetTypeBySlot: 0->2v2, 1->3v3, 2->5v5)
  3. Get BG template BATTLEGROUND_AA (all arenas)
  4. Create temporary group if solo (new Group()->Create(player))
  5. Validate leader, get arena team rating & matchmaker rating
6. grp->CanJoinBattlegroundQueue(bgTemplate, bgQueueTypeId,
     arenatype, arenatype, true, TeamSizeIndex, errorGuid)
7. bgQueue.AddGroup(player, grp, team, bracketEntry, false,
     arenaRating, matchmakerRating)
  8. Send SMSG_BATTLEFIELD_STATUS_QUEUED to all members
  9. ScheduleQueueUpdate(matchmakerRating, bgQueueTypeId, bracket_id)

HandleBattleFieldPortOpcode(BattlefieldPort)
  1. Validate player in queue, get bgQueueTypeId from ticket
  2. Get GroupQueueInfo from queue
  3. Verify player was invited (IsInvitedToBGInstanceGUID)
  4. If AcceptedInvite:
     - Check deserter (for BG), level, freeze aura
     - Set battleground entry point
     - Resurrect if dead, stop taxi
     - Send SMSG_BATTLEFIELD_STATUS_ACTIVE
     - bgQueue.RemovePlayer(guid, false)
     - SetBattlegroundId, SetBGTeam
     - BattlegroundMgr::SendToBattleground() (teleport to arena)
  5. If decline:
     - Send SMSG_BATTLEFIELD_STATUS_NONE
     - RemoveBattlegroundQueueId, bgQueue.RemovePlayer(guid, true)
     - ScheduleQueueUpdate for non-arena queues

=== 3. GROUP SIZE RULES ===

2v2 (ARENA_TYPE_2v2): TeamSize=2, MinPlayersPerTeam=2, MaxPlayersPerTeam=2
3v3 (ARENA_TYPE_3v3): TeamSize=3, MinPlayersPerTeam=3, MaxPlayersPerTeam=3
5v5 (ARENA_TYPE_5v5): TeamSize=5, MinPlayersPerTeam=5, MaxPlayersPerTeam=5

Rated Arena: Requires ArenaTeam of matching size
  (teamId from player->GetArenaTeamId(slot))
Skirmish (Unrated): No arena team required, any group of correct size
Group leader must queue; all members added automatically
Solo player: temporary group created in HandleBattlemasterJoinArena

=== 4. WHO MAY QUEUE ===

Requirements (checked in CanJoinBattlegroundQueue):
- Must be group leader (for group queue)
- Not already in battleground
- Not have Deserter debuff (spell 26013 / CHECK)
- Not in LFG queue (for solo)
- Has free battleground queue slots (PLAYER_MAX_BATTLEGROUND_QUEUES = 2)
- All members same level bracket (5-level brackets:
    10-14, 15-19, ..., 110-114, 115-119, 120)
- All members have same arena team for rated (checked via arenaSlot)
- Not have Freeze debuff (spell 9454)
- Not mercenary-contracted to opposite faction for rated
- For rated: group size == arena type (2/3/5)
- For skirmish: group size <= arena type (can be filled by matchmaker)

Computer-controlled characters (bots):
- Can be in group with real player
- Must pass same level bracket check
- Must have arena team registered for rated (bot arena team system)
- Leader (real player) calls HandleBattlemasterJoinArena
- Bots added as group members, queued together

=== 5. MATCH ASSEMBLY (BattlegroundQueue::BattlegroundQueueUpdate) ===

Called via:
- ScheduledQueueUpdate (after join/leave/port)
- Periodic forced update for rated arenas
    (CONFIG_ARENA_RATED_UPDATE_TIMER, default 30s)

Process per bracket:
1. CheckPremadeMatch() - Rated arena / premade BG
   - Finds first uninvited Alliance premade + first Horde premade
   - If both exist: create match, fill to MaxPlayersPerTeam
   - After CONFIG_BATTLEGROUND_PREMADE_GROUP_WAIT_FOR_MATCH
    (default 30 min), move premade to normal queue

2. CheckSkirmishForSameFaction() - Arena Skirmish
     (unrated, same faction allowed)
   - Builds selection pools from normal queues (both factions)
   - Tries to fill MinPlayersPerTeam per team
   - Allows same-faction matches

3. CheckNormalMatch() - Normal BG / non-rated
   - Builds selection pools from normal queues
   - Balances teams (difference <= 2 players)
   - Invites groups until MinPlayersPerTeam met

4. CreateNewBattleground() creates Arena/Battleground instance
   - Sets bracket, instance ID, rated flag, arena type (team size)

5. InviteGroupToBG() for each group in selection pools
   - Sets IsInvitedToBGInstanceGUID, RemoveInviteTime (now + 80s)
   - Creates BGQueueInviteEvent (remind at 60s)
    and BGQueueRemoveEvent (expire at 80s)
   - Sends SMSG_BATTLEFIELD_STATUS_NEED_CONFIRMATION

Matchmaking factors:
- Rating window: first team's rating
    ± CONFIG_ARENA_MAX_RATING_DIFFERENCE (default 5000)
- Matchmaker Rating (MMR) used for rated arena matching
- Faction: Alliance vs Horde (skirmish allows same faction)
- Role: Not enforced in matchmaking (client Roles field informational)

=== 6. MEMBER LEAVES QUEUE ===

BattlegroundQueue::RemovePlayer(guid, decreaseInvitedCount)
  1. Find player in m_QueuedPlayers, get GroupQueueInfo
  2. Remove from group's Players map
  3. If invited to BG and decreaseInvitedCount: bg->DecreaseInvitedCount(team)
  4. If rated arena and group becomes empty:
     - Announce world exit (CONFIG_ARENA_QUEUE_ANNOUNCER_ENABLE)
     - ArenaTeam::MemberLost() / OfflineMemberLost() with opponent rating
  5. If group empty: erase from m_QueuedGroups, delete GroupQueueInfo
  6. If rated arena and group not empty and not invited:
     - Recursively remove ALL remaining members (force leave)
     - Each gets SMSG_BATTLEFIELD_STATUS_NONE

WorldSession::HandleBattlefieldLeaveOpcode()
  - Called on CMSG_BATTLEFIELD_LEAVE
  - Player->LeaveBattleground() if in BG
  - Or RemovePlayer from queue

=== 7. CHARACTER TOLD TO ENTER ===

Invitation flow:
1. BattlegroundQueueUpdate -> FillPlayersToBG -> InviteGroupToBG()
2. InviteGroupToBG() for each player in group:
   - Player->SetInviteForBattlegroundQueueType(bgQueueTypeId, instanceGUID)
   - Schedule BGQueueInviteEvent (remind at INVITATION_REMIND_TIME = 60s)
   - Schedule BGQueueRemoveEvent (expire at INVITE_ACCEPT_WAIT_TIME = 80s)
   - Send SMSG_BATTLEFIELD_STATUS_NEED_CONFIRMATION
    (timeout=80s, mapId, queueSlot)

3. Client sends CMSG_BATTLEFIELD_PORT with AcceptedInvite=true
4. HandleBattleFieldPortOpcode():
   - Validates invitation, checks deserter/level/freeze
   - Send SMSG_BATTLEFIELD_STATUS_ACTIVE
   - RemovePlayer from queue (decreaseInvitedCount=false)
   - SetBattlegroundId, SetBGTeam
   - BattlegroundMgr::SendToBattleground() -> TeleportTo(team start position)

=== 9. KEY DATA STRUCTURES ===

BattlegroundQueueTypeId (packed uint64):
  BattlemasterListId (uint16) - BATTLEGROUND_AA for arenas
  Type (BattlegroundQueueIdType: Battleground=0, Arena=1,
    Wargame=2, ArenaSkirmish=3)
  Rated (bool)
  TeamSize (uint8: 2, 3, 5)

GroupQueueInfo:
  map<ObjectGuid, PlayerQueueInfo*> Players
  Team (ALLIANCE/HORDE)
  JoinTime, RemoveInviteTime
  IsInvitedToBGInstanceGUID
  ArenaTeamRating, ArenaMatchmakerRating
  OpponentsTeamRating, OpponentsMatchmakerRating

PlayerQueueInfo:
  LastOnlineTime (offline cleanup after 5 min)
  GroupInfo pointer

=== 10. UNVERIFIED / NOTES ===

- Exact BfA 8.3.7 opcode values may differ from
    current TrinityCore master (12.x)
- Arena skirmish queue (CMSG_BATTLEMASTER_JOIN_SKIRMISH)
    may not exist in 8.3.7 TrinityCore; 4.3.4 had no skirmish
- Role-based matchmaking (healer/DPS pairing)
    not enforced in TrinityCore queue logic
- Cross-faction arena skirmish logic
    (CheckSkirmishForSameFaction) may behave differently in 8.3.7
- Bot/arena team integration for computer-controlled
    characters requires custom modules
- ArenaTeam::GetAverageMMR() and MemberLost() logic for rating updates
- WorldSafeLocsEntry for arena start positions
    (varies by map: Nagrand, Blade's Edge, Ruins of Lordaeron, etc.)
