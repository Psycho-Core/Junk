AFFIX POSITIONS — 8.3.7 / BfA season 4 (Awakened); historical Beguiling clarification

SEASON WARNING: Beguiling was the SEASON-3 affix and was replaced by Awakened in retail season 4. Therefore no Tides (155434), Void-Touched (155433), or Enchanted (155432) emissary had a season-4 retail placement in ANY dungeon listed below. For each: Beguiling world map/x/y/z and nearest landmark = NOT APPLICABLE, not merely missing data. Historical season-3 positions cannot be represented as simultaneous season-4 spawns. Operation: Mechagon's Junkyard and Workshop were not season-3 keystones. A private core may custom-enable both, but such custom placements are unverified.

METHOD: Each Awakened record below is a season-4 map POI in a preserved MDT-derived source file (repository snapshot, not a verified build-35662 retail spawn capture); the source file was last edited after season 4. Its POI data is not a verified retail creature spawn. Percent pair is (x/840*100, absolute(y)/555*100), rounded to 0.1%, of MDT's 840-by-555 map PANEL, from its TOP LEFT, using MDT's stored map-pin x/y. These are approximate UI-map percentages, NOT world x/y/z, zone-map percentages, or coordinates usable for creature spawning. MDT floor is its local sublevel index, not a separate map ID. The corresponding world (map ID, x, y, z) is (instance map ID below, unverified, unverified, unverified) for EACH listed pin; exact world elevation, facing and instance spawn GUID are unverified. The nearest named in-world landmark for EACH pin is unverified: a map pin without verified POI-to-world matching cannot prove a nearest landmark. For each location verify on a season-4 instance before using it as a spawn. Affix 120, +10; these are the four spire TYPES, not the clickable creature entry; spire creature pairs (user-supplied): Brutal 160984/161143, Cursed 161163/161164, Defiled 161166/161167, Entropic 161168/161169. Which pair member is clickable: unverified.

ROTATIONS: MDT's twelve indexed weeks fall into A={1,2,5,6,9,10} and B={3,4,7,8,11,12}. These are MDT rotation INDICES, not calendar dates or proof the 8.3.7 private core uses this order. Each A/B group should yield exactly four map pins per dungeon. A pin marked both appears in either. Empty-week placeholder POIs are excluded. Each dungeon section cites its individual MDT file; the conversion denominator is from DungeonTools.lua (sizex=840, sizey=555).
