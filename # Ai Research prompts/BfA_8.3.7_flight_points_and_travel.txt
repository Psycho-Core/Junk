WORLD OF WARCRAFT 8.3.7 (BUILD 35662) - FLIGHT POINTS, FLIGHT MASTERS, BOATS, ZEPPELINS AND
CITY PORTALS FOR LEVEL 1-120 CHARACTERS ON A TRINITYCORE-BASED SERVER, BOTH FACTIONS
================================================================================================
Compiled 2026-10-21. Every number below is either read from the 8.3.7.35662 client tables
(wago.tools DB2 export) or is marked unverified in the field where it appears. Nothing is
estimated except the two derived columns marked "derived" (path length in yards and the time
that follows from it).

SOURCES USED
  TaxiNodes, TaxiPath, TaxiPathNode, Map  - client DB2, build 8.3.7.35662 (wago.tools CSV).
  SpellName                               - client DB2, same build (portal, teleport, riding ids).
  nether.wowhead.com/tooltip/{spell,achievement,item,npc}/<id>  - live Wowhead tooltips.
  warcraft.wiki.gg  - Flight master, Transportation, Zeppelin tower, Pathfinder pages.

ID CONVENTION
  A bare number in the id columns is a client id of the type named in the column header.
  "unverified" means no source I could read resolves that field. It is never guessed.

1. HOW THE TAXI NETWORK IS STORED (what a server has to read)
------------------------------------------------------------------------------------------------
  TaxiNodes       1,035 rows. Columns: ID, Name_lang, Pos_0/1/2 (x,y,z of the roost the flight
                  master stands at), ContinentID (= Map.dbc id), ConditionID, CharacterBitNumber,
                  Flags, Facing, MountCreatureID_0/1.
  TaxiPath        5,344 rows.  ID, FromTaxiNode, ToTaxiNode, Cost.
                  Cost is a money cost in copper, NOT a travel time. Most rows are 0.
  TaxiPathNode   86,627 rows.  PathID, NodeIndex, Loc_0/1/2, ContinentID, Delay.
                  Delay is 0 on 86,384 of 86,627 rows, so it cannot be used as the flight clock.

  FACTION PER NODE
    TaxiNodes.Flags bit 1 = Alliance only, bit 2 = Horde only, bits 1+2 = both.
    Verified against known nodes: 2 Stormwind = 1, 23 Orgrimmar = 2, 80 Ratchet = 3.
    Other flag bits (4, 8, 16, 32, 64, 128) exist on 60 nodes; their meaning is not documented
    in the tables available here, so they are printed raw and not interpreted (see 9).
    MountCreatureID_0 is the Horde mount, MountCreatureID_1 the Alliance mount: 2224 wyvern,
    3574 bat (Horde); 541 gryphon, 3837 hippogryph (Alliance). Where a node has a mount only in
    one column the other faction cannot use that node.

  WHAT "UNLOCK" MEANS
    CharacterBitNumber is the index of the bit a character sets in its taxi mask when it talks to
    a flight master. That mask is what the server stores; there is no level field in TaxiNodes.
    In 8.3.7 a node becomes usable by visiting its flight master (or by a quest that teaches it),
    so the gate is reaching the zone, not a level. The exceptions are the nodes whose
    ConditionID is non-zero (printed in the node tables as cond=<id>); the condition table is
    not among the exports used here, so the exact condition is unverified.

  TRAVEL TIME
    The client DB2 carries no flight duration. The derived columns are:
      yd  = sum of the straight-line distances between consecutive TaxiPathNode points of that
            TaxiPath (3-D distance, client coordinates). This is the real flight length.
      min = yd / 32 / 60, i.e. the length divided by the 32 yards/second used by TrinityCore
            for taxi flights (core constant TAXI_FLIGHT_SPEED). If your core changes that
            constant the minutes scale linearly. Treat min as derived, yd as measured.

1.1  AT A GLANCE
------------------------------------------------------------------------------------------------
  Flight points in the document: 597. Alliance-only 195, Horde-only 188, both factions 206, and 8
  nodes carry neither faction bit (neutral/quest-gated). Capital nodes a companion needs most:
    Alliance: node 2 Stormwind, Elwynn (11 outbound links); node 6 Ironforge, Dun Morogh (14);
              node 2105 Tradewinds Market, Tiragarde Sound - the Boralus point (2).
    Horde:    node 23 Orgrimmar, Durotar (15); node 22 Thunder Bluff, Mulgore (15);
              node 1957 Port of Zandalar, Zuldazar - the Dazar'alor point (8).
  A taxi needs only the node bit: no riding skill, no Pathfinder, no level. Flying needs the
  Pathfinder achievements in section 6. Boats, zeppelins and portals are free and unrestricted.

7. WHEN THE CHARACTER CANNOT FLY
================================================================================================
  What a level 1-120 character can always do, in the order a companion AI should prefer it:
    1. Walk or ground-ride. Ground mounts need 33388 (level 10); nothing else is gated.
    2. Use a flight master taxi. Taxi travel needs no riding skill, no Pathfinder and no level;
       it needs the node bit set (CharacterBitNumber) and a TaxiPath to the destination.
    3. Use a boat, zeppelin or ferry. Free, no requirements, 60-second dock dwell (wiki).
    4. Use a portal or teleport: mage portal spells (section 5), the capital portal rooms, and
       the hearthstone.
    5. Get summoned through a summoning stone / warlock summon, which needs two other players
       and is therefore the fallback a companion group cannot do alone.
  Consequences for AI: a companion that cannot fly must be routed through the taxi graph in
  section 2, not along a straight line. The link blocks give the edges and the derived minutes,
  so a path search over 597 nodes and 3,046 edges is cheap enough to run at spawn time.

8. WHAT IS IN THIS DOCUMENT AND WHAT IS NOT
================================================================================================
  Verified from client tables (build 8.3.7.35662): every node id, name, map id, coordinate,
  faction bit, taxi-mask bit, mount creature column, every TaxiPath edge and its node geometry.
  Verified from Wowhead tooltips: every spell id quoted with a level or faction, the six riding
  spells, the five Pathfinder achievements, and the hearthstone items 6948, 110560, 140192,
  162973.
  Verified from warcraft.wiki.gg: flight master names per node, boat and zeppelin route pairs,
  zeppelin tower list, the 60-second dock dwell, the 2020-10-13 and 2023-03-21 changes that
  removed the Pathfinder flying requirement (which is what makes 8.3.7 the last patch where
  those three achievements were still required).

  Unverified, and left unverified on purpose:
    - transport game object entries (no Transports table in the export; TransportAnimation has
      only TransportID numbers with no names)
    - boat and zeppelin crossing times, and the dock coordinate for routes that have no
      "Transport, ..." taxi node (section 4 gives the twelve that do have one)
    - flight master creature entries that no Wowhead lookup resolved (section 3.2 lists them with
      name and mount type only). The reason is measurable: the client Creature export this build
      allows is a 13,608-row sample spanning creature ids 3 to 164,142 (checked: only 137 rows
      below id 20,000), so it cannot be used as a name->entry index, and Wowhead is only
      reachable through a rate-limited reader that returns a few lookups per minute.
    - the meaning of TaxiNodes.Flags bits 4, 8, 16, 32, 64 and 128 (the faction bits 1 and 2 are
      proven; nothing in the tables available defines the rest)
    - PlayerCondition rows that carry no level, class, race or quest column (printed as "row
      exists, no decoded field"); the requirement for those nodes lives in columns this export
      does not decode
    - per-node level requirements: none exist in the client table; the gate is zone access
    - Argus flying: stated as none, but not provable from the tables used here
