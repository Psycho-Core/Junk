3. BEST SPECIALIZATION FOR DUNGEON BOOSTING AND WHY
----------------------------------------------------
Best Specialization:
- Havoc (ChrSpecialization ID 577, Role: Melee DPS, Resource: Fury [PowerType 17, max 100/120], Spec Passive: Havoc Demon Hunter Spell ID 212612).
- Other Demon Hunter Spec (Not Selected): Vengeance (ChrSpecialization ID 581, Role: Tank, Resource: Pain [PowerType 18, max 100], Spec Passive: Vengeance Demon Hunter Spell ID 212613).

Why Havoc (Spec ID 577) Is Right for a Companion Dungeon Booster:
1) Multi-Pack AoE Kill Speed (the XP Engine):
   - Eye Beam (Spell ID 198013, channeled) and Blade Dance (Spell ID 188499, hits up to 5 enemies with reduced damage beyond 5) are the two pack-clearing abilities; inside Metamorphosis they upgrade to Annihilation (Spell ID 201427) and Death Sweep (Spell ID 210152, 35 Fury, 9 sec cooldown).
   - Metamorphosis (Havoc, Ability Spell ID 191427, 40 yd, 4 min cooldown in Patch 8.3.7): leaps to the location, stuns enemies for 3 sec (players Dazed 3 sec), then transforms the Demon Hunter for a 30 sec demon form (Metamorphosis form Spell ID 162264) that grants +25% Haste and +20% Leech - burst, speed and sustain in one cooldown.
   - Talents that multiply the clears: First Blood (Talent ID: unverified, Spell ID 206416) lowers Blade Dance cost and boosts its primary-target damage; Immolation Aura (Talent ID: unverified, Spell ID 258920) adds Fury-generating Fire cleave to every pull; Trail of Ruin (Talent ID: unverified, Spell ID 258881) adds a DoT to every Blade Dance target; Fel Barrage (Talent ID: unverified, Spell ID 258925, 10 Fury, 1.5 min cooldown) is an 8 sec close-range storm for elite packs.
   - Key Havoc azerite traits on ilvl 280+ BfA quest/Island Azerite pieces: Eyes of Rage (Power Spell ID 278500: Eye Beam crits reduce Eye Beam cooldown, Soul Fragments shave 0.7 sec each), Furious Gaze (Power Spell ID 273232: Haste after a full Eye Beam channel), Revolving Blades (Power Spell ID 279581: Blade Dance/Death Sweep damage and Fury cost).
   - Chaos Brand (Spell ID 255260): every mob the booster hits takes +5% magic damage from the whole party (available on Vengeance too, but free on this AoE-cleave spec).
2) Self-Sustain With No Tank Stats:
   - Soul Rending (Havoc Talent ID 21863, Spell ID 204909): +10% passive Leech and +10% additional Leech while Metamorphosis is active in Patch 8.0.1-8.3.7; the demon form adds its own +20% Leech, so big pulls convert directly into healing.
   - Demonic (Havoc Talent ID 21900, Spell ID 213410): Eye Beam triggers Metamorphosis windows (burst cycle roughly every 30 seconds), multiplying leech and haste uptime; Demonic Appetite (Talent ID: unverified, Spell ID 206478) converts Soul Fragments into bonus Fury instead of needing the Vengeance fragment-heal loop.
   - Gear-independent defenses: Blur (Spell ID 198589, Buff Spell ID 212800: +50% Dodge and 20% damage reduction for 10 sec, 1 min cooldown), Desperate Instincts (Talent ID: unverified, Spell ID 205411: extra Blur reduction and auto-trigger below 35% health), Netherwalk (Talent ID: unverified, Spell ID 196555: 100% damage immunity and +100% speed for 5 sec, 2 min cooldown), Darkness (Spell ID 196718, Absorb Trigger Spell ID 209426: 20% chance to avoid all damage in an 8 yd zone for 8 sec, 3 min cooldown), plus Legion Legendary Raddon's Cascading Eyes (Item ID 137061, Equip Spell ID 215149) when farming Eye Beam resets.
   - Honest limits: Havoc gets no tank armor and no melee critical-hit immunity - Havoc Demonic Wards (Spell ID 278386, added in Patch 8.0.1) is only -10% magic damage taken. That is acceptable at level 111 in green-difficulty BfA Normal dungeons because packs die during the opener and Soul Rending/potions cover the rest (the unselected spec keeps the raw-survival package: Vengeance Demonic Wards Spell ID 203513 with -15% all damage, +65% Stamina, +100% bonus armor and melee crit immunity).
3) Mobility, Control, and Pull Pacing:
   - Fel Rush (Spell ID 195072), Vengeful Retreat (Spell ID 198793), Glide (Spell ID 131347) plus Double Jump (Spell ID 196055), and the 40 yd Metamorphosis leap make Havoc the fastest spec for chain-pulling corridors - the route's cooldown lines use exactly these (Dungeon111_Route.txt section 2).
   - Control: Chaos Nova (Spell ID 179057, 2 sec AoE stun, 1 min cooldown, procs Sephuz's Secret), Imprison (Spell ID 217832, 60 sec incapacitate on Demon/Beast/Humanoid without pulling combat - clean patrol skips), Disrupt (Spell ID 183752, 10 yd kick that restores Fury on a successful interrupt), Consume Magic (Spell ID 278326, purge that strips Freehold/Atal'Dazar/Motherlode trash shields and buffs).
   - Threat reality: Havoc carries only the 1.0x damage-threat of a DPS spec (no taunt, no Vengeance +350% threat modifier Spell ID 189926), so the boostee stays 30-60 yards behind and the booster opens each pack with burst AoE - the route's pull rules already assume this and packs die before enemies run.

Why Vengeance (Spec ID 581) Was Not Selected:
- Vengeance offers stronger raw mitigation (Demon Spikes Spell ID 203720, Fiery Brand Spell ID 204021, cheat-death Last Resort Talent Spell ID 209258), pack stacking (Sigil of Chains Talent Spell ID 202138), instant tank-queue pops and the +350% threat modifier - its job is holding damage, not ending fights. For this booster set the specification is Havoc (ChrSpecialization ID 577): it kills whole packs fastest, sustains through Soul Rending leech instead of armor, and avoids the unscripted sigil/fragment systems on a stock TrinityCore 35662 core.
