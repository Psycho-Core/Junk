1. THE ONE PLACE THE WARLOCK FILE DELIBERATELY CONTRADICTS THE PRIEST FILE
   1  PASS  Bracers. The priest file takes 13642 Enchant Bracer - Spirit
      (+5 Spirit) because a healer lives on Spirit; this file takes 13622
      Enchant Bracer - Lesser Intellect (+3 Intellect, two Greater Astral
      Essence, Runed Silver Rod) and says why (V, both spell tooltips).
      The reasoning is sound: Spirit gives a warlock no damage, and in BfA
      it does not give meaningful in-combat regeneration either.
   2  PASS  The weapon oil flips the same way: 20744 Minor Wizard Oil, +7
      Intellect, requires 5 (V) for the warlock, 20745 Minor Mana Oil, +7
      Spirit (V) for the priest. 20746 Lesser Wizard Oil at +15 Intellect
      requires level 30 (V), one level past the bracket, so it is out.
   3  PASS  6373 Elixir of Firepower, +10 fire spell damage for 30 min,
      requires 18, spell 7844, from the Alchemy file. The claim that this
      elixir is worth more to a warlock than to a priest is right for
      Destruction - Immolate, Conflagrate and Chaos Bolt are fire - and the
      file is honest that Affliction and Demonology get nothing from it.

2. THE CORRECTION THAT IS NOT IN THIS FILE
   4  CORRECTED (other file)  This file states that Arcane Torrent stopped
      being a silence in 8.0.1: "Now removes 1 beneficial magic effect from
      all enemies (was a silence)" and the cooldown went from 1.5 to 2
      minutes (V, wiki patch line). The priest file in this set, line 162,
      still describes the blood elf racial as "an area silence and mana
      return", which is pre-8.0.1 text. That is a live error in a merged
      file and it is recorded here so the priest set can be corrected in a
      later pass; this audit did not edit it, because the priest set is
      already merged and a cross-set edit belongs in its own commit.
   5  CORRECTED  The same paragraph of this file originally called the
      racial a "purge" without saying what it removes. The wiki says one
      beneficial magic effect from all enemies within 8 yards, plus 3% of a
      warlock's mana (V, class table). The file now carries both numbers.
      Note the class table is a current table; 3% is also the 6.0.2 figure,
      so the number is safe, but it was not read off an 8.3.7 page.
