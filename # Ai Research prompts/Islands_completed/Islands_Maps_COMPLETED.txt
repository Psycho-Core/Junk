=== ISLAND EXPEDITIONS - MAPS - BFA 8.3.7 (TRINITYCORE) - COMPLETED ===

Context: Battle for Azeroth Island Expeditions, 3-player scenarios (PvP mode 3v3).
11 islands in the weekly rotation (3 offered per week), plus the Uncharted
Island tutorial map. Sources: warcraft.wiki.gg (Island Expedition, island
pages); world DB updates from TCDEVEmu/AtalDazar_BFA (8.3.7 server SQL,
VerifiedBuild 28153); TrinityCore sql/old/8.x world_safe_locs dump (retail
8.x line); MTT-WoW-BfA SQL (cross-check, identical rows); HavenWoW/BFA-
HavenCore SharedDefines.h; TC map_difficulty hotfix rows (build 34963);
RareScanner addon rare list; guide sources for the Azerite totals (Icy Veins,
MMO-Champion, worldofmoudi, mmoauctions, Gamepur).

1. OBJECTIVE - AZERITE TOTAL PER DIFFICULTY (the race target, same on every
   island; first team to the total wins):
   Normal 6,000 Azerite.
   Heroic 9,000 Azerite.
   Mythic 12,000 Azerite.
   PvP 12,000 Azerite (same as Mythic; PvP win also gives Conquest).
   Weekly quest total: 36,000 Azerite per week (was 40,000, reduced in
   patch 8.1; warcraft.wiki.gg patch notes) - 6 Normal or 4 Heroic or
   3 Mythic/PvP wins (Icy Veins).
   Difficulty ids (server data): 38 = Normal, 39 = Heroic, 40 = Mythic
   (MaxPlayers 3), 45 = PvP (MaxPlayers 6) - map_difficulty rows for map
   1882 (IDs 4096/4097/4098/4171, build 34963); names also confirmed by
   HavenCore enum LOOT_MODE_NORMAL/HEROIC/MYTHIC/PVP_ISLAND = 38/39/40/45.
   Difficulty 153 appears in TCDEVEmu spawnDifficulties/lfg rows (their
   lfg names call it "pvp"); HavenCore enum names 153 = Teeming Island.
   Which tag is retail-correct for 8.3.7 on a second difficulty: unverified.

3. AZERITE NODES / CHESTS / EVENTS - SPAWN AND RESPAWN BEHAVIOUR.
   - Which nodes, chests and event objects exist on an island is rolled
     per queue: warcraft.wiki.gg (Island features) - "Each time an Island
     Expedition is queued up, the island has different features",
     "Chests and Azerite Nodes of all kinds", capture points, quest
     givers, consumables and shrines; overgear guide: "Treasure Chests
     and Azerite Nodes of all kinds spawned randomly around the Island".
   - In one run a depleted node despawns when the gather cast completes
     (player bug reports on US/EU forums 2018-2026: nodes "despawn when
     the cast for gathering is finished"). In-run respawn timer:
     unverified.
   - Server spawn rows that DO exist (TCDEVEmu, Verdant Wilds): all 67
     gameobject rows and all 180 creature rows carry spawntimesecs 7200
     and spawnDifficulties '38' as shipped (later island.sql widens the
     map to 38,39,40,45). Whether 7200 is the retail respawn value or a
     server default: unverified.
   - Azerite node positions for 10 of 11 islands: unverified - no
     readable public dump contains their spawn pools; they are re-rolled
     per expedition by design.
   - Azerite node positions for Verdant Wilds: section 4.
